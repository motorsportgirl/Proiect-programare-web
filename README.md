# HobbyPall 🎯

O platformă web care conectează oameni cu pasiuni comune prin organizarea și participarea la evenimente.

## Tehnologii folosite

- **Python & Flask** — backend și rutare
- **SQLite** — baza de date
- **Jinja2** — templating HTML
- **PicoCSS** — stilizare frontend
- **Flask-Mail / smtplib** — trimitere emailuri
